# UMW-GBUS-562
Repository for GBUS-562

## About
This repository contains materials created for GBUS 562: AI Language Models at the University of Mary Washington (UMW). Content is organized into folders by week.

## Weekly Work
1. [week-01](week-01/)
   - [Connect Four](week-01/connect4.html): a single-page browser game built with HTML, CSS, and JavaScript. Play against a computer opponent that uses minimax search with alpha-beta pruning (Easy, Medium, and Hard levels), or switch to two-player mode to take turns with a friend on the same device.
2. [week-02](week-02/)
   - [Prompt Lab](week-02/prompt-lab.html): a Prompt Lab web app for testing prompts against Claude, built with Claude Code.
3. [week-03](week-03/)
   - A RAG tool that answers questions from Copperline Manufacturing's finance documents, built with Claude Code. Source documents are in [copperline-docs](week-03/copperline-docs/).
4. [week-04](week-04/)
   - Week 4: an AI agent that prepares replies to HR emails using tools from an MCP server, built with Claude Code. Source materials are in [hartwell-hr](week-04/hartwell-hr/).
5. [week-05](week-05/)
   - Week 5: a team of AI agents that prepares a bicycle maker's response to supplier emails, built with Claude Code. Source materials are in [brookfield-bikes](week-05/brookfield-bikes/).
6. [week-06](week-06/)
   - Week 6: an evaluation and a code guardrail for the first version of my [capstone](capstone/), an AI problem-framing tool, built with Claude Code. Includes the [test cases](week-06/test-cases.csv), the [evaluation program](week-06/capstone_evaluate.py), and the [saved runs](week-06/runs/).
   - The optional lecture exercise, a service desk assistant, is in [assistant.py](week-06/assistant.py), with source materials in [alder-creek](week-06/alder-creek/).
7. [capstone](capstone/)
   - Capstone: an AI problem-framing tool that helps one person turn a concern, idea, or proposed solution into a clear, user-confirmed problem frame, built with Claude Code. Sources for its external MITRE guidance are in [mitre-sources.md](capstone/mitre-sources.md).
